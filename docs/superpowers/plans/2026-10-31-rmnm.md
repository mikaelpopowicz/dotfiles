# rmnm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a polished interactive `rmnm` zsh function that finds pruned `node_modules` dirs, shows sizes, supports all/select + dry-run, and prints a final space report.

**Architecture:** One public `rmnm` plus private `_rmnm_*` helpers in `shell/.functions`, using `find`/`du` for data and `gum` for TUI (spin, choose, filter, confirm, style).

**Tech Stack:** zsh, gum 2.x, macOS `find`/`du`/`rm`

## Global Constraints

- Live in `shell/.functions` only (no new bin script)
- Require `gum`; fail fast if missing
- Prune: do not descend into found `node_modules`
- Sizes via numeric `du -sk`; human-format for display; sum KiB then format
- Always emit a final report (deleted or would-free)
- Cancel/Esc → exit 0, no deletions
